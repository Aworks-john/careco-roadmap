CareCo Product Roadmap — deploy folder

Upload the contents of this folder (not the folder itself) to any static host.

GitHub Pages:
1. Create a repo, upload index.html, support.js and the assets folder to the root.
2. Settings → Pages → Source: "Deploy from a branch" → main / (root) → Save.
3. The site will be live at https://<username>.github.io/<repo>/ within a minute or two.

Keep the folder structure as-is — images load from assets/products/.
